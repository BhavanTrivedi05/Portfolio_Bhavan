01SYS·GATEWAY

CyberGuard Gateway

API gateway / web application firewall · Java · Spring

A servlet-filter WAF that inspects every request before it reaches a service: SQL-injection and XSS scanning, sliding-window rate limiting, JWT auth, IP filtering, and security-event logging. The filter chain is ordered so the body can be re-read by later stages — the gotcha most people trip on.

03 · operator profile

About

I build backend systems and I care how they behave under load. Not just whether an endpoint returns 200, but the query plan behind it, the filter that sits in front of it, and what happens when the traffic isn't friendly.

I'm an MSCS student at Northeastern in Boston. Most of my work lives in the Java / Spring ecosystem on top of PostgreSQL, with a soft spot for the security layer — WAFs, auth, rate limiting — because that's where correctness actually gets tested.

My rule for projects is brick by brick, always deployed: get one real slice working end to end and shipped before adding the next. It keeps the defect count low and the demo honest.
